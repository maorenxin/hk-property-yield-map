# 中原全历史回填（2026-10-18，完成）

## 方法

- 中原公开 API `POST /centanetapi/api/Transaction/Search` 使用未公开的 `day=""` 模式；实测返回全历史，不受 `Day1095` 三年限制。
- 按**楼宇组 `bldgGrpID`** 回填，避免全港 2.6M 条无差别抓取；每条请求按登记日期窗口拆分，单查询保持 `offset+size <= 10000`。
- 原始分页写入 `data/raw/centaline/transaction_search_full/2026-10-18/pages/`，可断点续跑；合并时按记录 `id` 去重。
- 同时保存 `registration_date`（登记日）与 `deal_date`（`insDate` 成交日）；分析使用 `deal_date`，展示保留登记日用于与官网对账。

## 结果

- 归一化记录：**1,806,339 条**（买卖 1,650,417 / 租赁 155,922），覆盖 **2,084 个屋苑、2,284 个楼宇组**；日期 **1990-01-12 ~ 2026-10-18**；按月抓取分页 **22,211 个**。
- 成交日范围：**1990-01-12 ~ 2026-10-18**。
- 全历史页缓存已覆盖 **1,406/2,278 个楼宇组**（16,829 个全历史分页文件）；剩余 **872 个楼宇组**保留 3 年快照。
- 全历史回填分页：**16,829 个全历史页文件**；本地 API 后续触发配额 429，改用日本出口续跑；日本出口也在大批量后触发 429，已保留所有成功页并停止，未伪报全量完成。
- 验证样例：红磡 **興利大廈（HMA090:KC0135）**：
  - 全历史 **55 宗买卖、0 宗租赁**；
  - 最早 **1995-08-15（登记）/ 1995-07-22（成交）**；
  - 详情页现在展示最新 60 宗并分页读取，包含 2023-06-14 等 3 年快照外的记录；完整记录写入全量 Parquet。
