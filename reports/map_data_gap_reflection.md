# 地图数据缺口反思（2026-10-19，2026-11-02 更新）

## 2026-11-02 地址级补点修复

- 新增通用“孤儿楼宇”管线：当父楼宇组没有坐标，或记录没有 `bldgGrpId`，按 `hma_id + address_raw` 建立地址级楼宇点。
- 坐标来自中原 `mapproject/api/Estate/Brief`，同时核对返回地址；允许同一街道的号段/门牌范围，拒绝不同街道或明显错误坐标。
- 共识别 **1,049 个缺失地址**，成功补建 **1,040 个地址级点**；其中 **440 个**有可发布回报率；**9 个**因跨号段/相邻门牌冲突保留为未解析，见 `data/derived/orphan_points_unresolved.csv`。
- 用户提供的 PDF 中 7 个不重复楼盘现均可搜索和定位：瑧蓺、瑧璈、縉城峰、尚嶺、藝里坊．1號、星鑽、藝里坊．2號；其中縉城峰原本已有楼宇组点，其余 6 个由地址级点补齐。
- 地址级点使用独立 ID，并生成自己的历史序列、成交明细和学校数；地图绘制为虚线描边圆点，避免与父楼宇组点混淆。
- 搜索结果增加精确名称优先门禁：例如“星鑽”现在只返回西营盘星鑽，不再把“星鑽匯”等包含同字的其他楼盘混进结果。

## 仍然漏掉或没有 plot 的

### 1. 租务落组仍有缺口

- 28Hse：22,587 条中 **2,902 条未落组**（乐悠居、单幢/街号盘为主）。
- Midland：32,592 条中 **10,323 条未落组**。本轮新增 3,589 条（将军澳中心、海之恋、嘉亨湾、名城、珑门、栢慧豪园、港湾豪庭、维景湾畔、泓景台、德福花园、浪澄湾、迎海、新港城）；剩余重点是皓畋、东环、宇晴轩、丽港城、大兴花园、贝沙湾等。
- 美孚新邨仍有 **247 条 28Hse + 46 条 Midland** 因门牌缺失/跨组歧义保留未落组。
- 这些记录不是“没有抓到”，而是无法可靠落到现有楼宇组；用低分模糊匹配会制造错误，所以留在 audit。

### 2. 学校已有蓝点图层，但缺“质量/校网”

- 学校点/大学校园已经以蓝点 + 校园轮廓显示，可单独开关；当前仍没有按学校类型细分图层。
- 教育局数据是**点位**，不是校网/派位范围；没有小学 POA 校网、banding、校车/步行时间。
- 同址同名多记录已合并为一所；多校区学校可能被合并，需按校区名再拆分。
- 大学用 25 个 OSM `amenity=university` campus 多边形 + 91 个 iGeoCom 大专点；部分校园/分校未被 OSM 标记，可能低估。
- 1km 是**直线距离**，没有考虑天桥、隧道、海港、山坡、步行绕路；后续可做 1km 步行等时圈。

### 3. 回报率覆盖仍不是“全部楼宇”

- 2,282 个楼宇组中 **1,575 个有回报率**；1,971 个楼宇组点有坐标；地图通过 1,040 个地址级补点覆盖原先无坐标组的可见楼宇。
- **695 个组没有租赁记录**，8 个组没有买卖记录；643 个地图点位是灰色/无回报率。
- 80 个组没有入伙年份；楼龄筛选开启时会被隐藏。
- 466 个楼宇组坐标是屋苑中心近似，2 个是合成组；不是每栋都有精确坐标。
- 建筑轮廓只有 **564 组**（434 name / 87 near / 13 OSM）；其余约 1,410 个点位没有轮廓，只能继续用气泡。

### 4. 租务历史的口径限制

- 中原租赁最早约 **2021-01**；没有 2021 年以前的逐单租赁。
- 香港一般住宅租约不在土地注册处登记；不存在全市场逐单租务成交库。
- 中原是自家经手，28Hse/Midland 是市场申报；三者不是同一口径，跨源只做保守去重/对账。
- 当前租赁 155,922 条（中原 + 补充），但仍是“可获得的公开租务记录”，不是全市场租赁成交。

### 5. 还没有 plot 的城市数据

- 交通：MTR/巴士/小巴站、步行时间、通勤时间。
- 生活：医院/诊所、商场/超市、公园/运动场、图书馆。
- 风险：噪音、空气质量、洪水/斜坡风险、犯罪、旧楼维修状态。
- 学校：校网、banding、学费、国际学校课程、幼儿园名额。
- 这些不是当前“租售比”核心，但会显著影响居住价值和租金。

### 6. 图片与详情

- 画廊已有 10,450 张 WebP（每组最多 6 张）；1 个上游 URL 404，未进入本地映射。
- 图片是中原成交附图/街景，不是每栋完整外立面；不能替代实地看楼。
- 详情明细每侧最多加载最近 60 宗，翻页只在前端已加载集合内；全量历史在 Parquet，不在前端一次性加载。

## 优先级建议

1. **学校蓝点图层已完成**；下一步加“学校类型”筛选、POA 校网/banding/学费。
2. **继续 Midland 10,323 / 28Hse 2,902 的落组**，优先大屋苑；美孚剩余 293 条单独人工复核。
3. **把 1km 直线距离升级为步行等时圈**（OSM/步行网络），尤其对海港、山坡、快速路阻隔的区域。
4. **继续处理 9 个地址级未解析点**（街道号段跨多栋或中原返回相邻门牌）；缺楼龄组继续用 RVD/28Hse 补。
5. **扩建筑轮廓覆盖**：当前只有 564 组，优先把有回报率且高样本的组补到官方轮廓。
6. 视产品需要再加交通/生活/风险图层；不要在没有口径说明的情况下把“距离”当成“质量”。
