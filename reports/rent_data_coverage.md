# 租务数据覆盖与第二来源调研（2026-10-18 更新）

## 1. 结论

1. 香港一般住宅租约（≤3 年）**不在土地注册处登记**，不存在全市场逐单租务成交库。
2. 中原地產公开 API 的 `day=""` 实测可返回**全历史**：买卖最早 **1995-06**，租赁最早 **2021-01**；租赁仍全部是中原自家成交（`dataSource=AC`）。
3. 我们当前已启动**按楼宇组全历史回填**：不再受 3 年 `Day1095` 限制；回填后每个楼宇组的买卖/租赁历史以该组自身记录为准。
4. 第二租务来源：
   - **28Hse**：屋苑级租务成交列表可按页抓取，实测可回溯约 5 年；已扫描 **1,435 个已映射屋苑**，取得 **22,587 条**租务成交（19,685 条可归属，128 个楼宇组，387 个有数据屋苑），并抓取 **229 栋**当前租盘。
   - **Midland / HKP**：3 年内租务成交丰富；本机 CloudFront 403，已改经 **GPU 主机 + 访客 JWT** 映射 **1,869/1,972 个楼宇组、1,106 个屋苑**，抓取 **32,592 条**原始租务，归属 **22,269 条、627 个楼宇组**。
   - **House730**：3 年多来源成交，但 ToS 明确限制复制/分发，未接入。
   - **RVD / C&SD**：官方宏观租金/回报率基准，不能替代楼栋级租务成交。
5. 因此 UI 必须区分：
   - **租务成交**（中原 + 28Hse + Midland；历史深度因来源而异）；
   - **当前租盘/叫租**（28Hse，不是成交）；
   - **官方租金/回报率指数**（RVD/C&SD，宏观校验）。

| RE 买卖 | 2,083,646 | 160,859 |
| RE 租赁 | 151,558 | 79,747 |

- 最早买卖：1995-06-15；最早租赁：2021-01-01。
- 单查询分页上限：`size<=100`、`offset+size<=10000`；全历史必须按楼宇组/时间窗/来源拆分。
- 日期口径：`oldTransactionID` 前 8 位是登记日；`insDate` 是成交日。本轮开始同时保存 `registration_date`、`deal_date`、`analysis_date`（成交日优先），避免把登记日当成交日。
- 本地当前 3 年快照仍完整：296,708 条，2023-10-17 ~ 2026-10-16；按年分布不是“只有 2026”。

## 3. 28Hse 第二来源

- 租务成交页：`https://www.28hse.com/estate/detail/<slug>/transaction/rent/page-N`
- 字段：单元级 座/层/室、成交日、实用面积、月租、呎租、市场成交标签、原纪录链接。
- 本轮：共 **22,587 条**（其中 **19,685 条**可归属到 128 个楼宇组），日期覆盖 **2021-03-12 ~ 2026-10-18**。六个试点屋苑已到各自末页：匯璽 643 页、太古城 377 页、嘉湖山莊 324 页、新都城 239 页、美孚新邨 199 页、海茵莊園 144 页；其余已映射屋苑最多 3 页。
- 出口与限流：本机第 101 页起 HTTP 403；`ssh gpu` 出口跑完了六个试点的末页；中途 12 个 TLS 失败页已自动重试并补齐。对 403/429 均不伪报为“抓完”。
- 当前租盘：从已缓存的 28Hse 屋苑页跟进 `c<id>` 租盘列表，覆盖 **229 栋**；只作为叫租参考，不并入成交租金。
- Midland：经 `ssh gpu` 调用内部 `search/v2/transactions`，取 `tx_type=L`；映射 **1,869/1,972 个楼宇组、1,106 个屋苑**，抓取 **32,592 条**原始租务，归属 **22,269 条、627 个楼宇组**（2022-06 ~ 2026-10；另 1 条 2017 异常）。token 经 stdin 传入，未写入命令行或仓库。
- 三源去重：按楼宇组 + 日期 + 租金 + 面积 + 可解析层/室 token 跨来源去重；没有层/室 token 的记录保留。指标管线全量 **1,837,438 条**，较中原原始增加 **31,099 条**。
- 局限：分页深度因屋苑而异；超过最后一页会重复；租务成交为市场/经纪申报，不是土地注册处登记；跨来源必须按 `屋苑+座+层+室+日期+租金+面积` 去重。

## 5. 产品处理

- 详情页「租」Tab 分开显示：成交宗数、当前 28Hse 租盘数/叫租中位、28Hse 历史成交摘要；成交明细来源徽标显示 `AC`、`MIDLAND` 或 `28HSE`。
- 地图/详情来源徽标区分 `中原`、`土地注册处`、`28Hse`；租盘明确标注“叫租，不是成交”。
- 全历史回填完成后，楼栋走势使用 `analysis_date`（成交日优先）计算；详情表同时保留登记日期用于对账。
