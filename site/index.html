口径声明：这里的“租售比”是年化毛租金回报率 = 月租 × 12 ÷ 售价。RVD 历史层按同一月份、同一区域、同一房屋类别分别取公开平均值；Centaline 明细层按同一月份、同一 18 区、同一实用面积段配对。地图同时展示两层，但不把当前样本快照当成长期历史指数。数据来源差异：买卖成交来自土地注册处（全市场登记）；租务成交为中原地产自家经手，并补充 28Hse 当前租盘（叫租，不是成交）。香港一般住宅租约不在土地注册处登记，不存在全市场逐单租务成交库，因此同一楼宇的「售/租」宗数不可直接对比覆盖率。

如何读图

回报率在同一楼宇组内部用租金呎价与售价呎价配对计算；近 12 个月快照用于当前值，全历史走势为近 3 个月滚动中位，租/售两侧各 ≥1 宗才发布，灰色或无走势表示样本不足。楼龄按每栋的入伙年份取中位、再在楼宇组内跨栋取中位；街区型混合楼龄组会标注组内年份范围（如 1959–2024）。默认筛选为回报率 >3%、楼龄 ≤30 年；学校数按 1 公里缓冲区计算，幼儿园/小学/中学为教育局点位，大学为校园轮廓，边界触达也计入。

口径与命名

报告统一使用“港岛、九龙、新界”，金额统一为港币：呎价 = 每平方呎售价（HK$/呎），呎租 = 每平方呎月租（HK$/呎/月）；税费、管理费未扣除，属年化毛回报率。

匹配管线：四道闸门

01 先归一NFKC、繁简异体、全半角、空格与装饰字符；phase/tower 转成可比较 token。
02 再精确重点屋苑用固定 phase + tower / 台 + 阁名表；匯璽 II/III 优先于数字期数。
03 才模糊只在同屋苑、同 phase 内比较；分差不足 15 分或 phase/tower 冲突时判为 ambiguous，不落组。
04 留审计未匹配、歧义、冲突、候选组、置信度写入 audit；不能静默丢记录。
硬门槛：多个组的屋苑禁止只凭“太古城 / 日出康城 / 匯璽”这类共同前缀落组；只有屋苑名时进入 audit。

来源口径：先分清“来源”与“登记处”

买卖土地注册处登记（Land）为主；中原 API 同步，另有少量中原经手 AC 记录。
租赁中原 AC + 28Hse + Midland；香港普通住宅租约不在土地注册处登记，不能把租务当成全市场逐单库。
当前租盘28Hse 叫租，不是成交；不并入租金中位数。
跨源对账同一组、同一层/室、租金与面积一致：同日 exact；相差 1 天 date_shift_1d；超过 1 天不自动配对。
所以详情表的“土登”不是另一家地产，而是土地注册处登记；如果某组没有中原 AC 成交，表中会明确显示0条，不会把 Land 错标成中原经手。

买卖会不会重复？

  • 28Hse / Midland 当前只接入 租务，不会新增买卖记录；它们不会和中原买卖跨源重复。
  • 中原买卖同时有 Land 1,649,677 条 / AC 740 条；当前审计出 63 个同组、同日期、同金额、同面积、同单元的双来源候选键。
  • 指标管线按可解析层/室 token 尝试 Land 优先去重；本快照实际扣除 63 条，未确认的记录保留，避免误删真实成交。
  • 租赁三源的跨源去重按同组 + 日期 + 租金 + 面积 + 层/室 token；不把叫租当成交。
